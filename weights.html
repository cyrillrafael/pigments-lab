Openness criteria
  1. Inclusion. Weights for at least one checkpoint can be downloaded by the public. Click-through gating is allowed; access by request or API only is not.
  2. Licence classes.
    1. L-A: OSI-approved or public-domain dedication, no field-of-use restriction.
    2. L-B: commercial use for everyone, with conditions limited to attribution, notice or share-alike.
    3. L-C: an acceptable-use policy that binds downstream users, a user or revenue threshold, a non-commercial clause, or a hosting limit.
    4. L-?: licence not verified.
  3. Openness score, 0 to 6. Licence L-A 2 · L-B 1 · otherwise 0; training code 1; training data full 2 · partial 1; technical report 1. Unknown counts as 0.
  4. Tiers, first match wins. I: L-A, training code and full data · II: L-A · III: L-B · IV: L-C · —: L-?.
  5. Verification. “Confirmed” entries match the official model card. “Reported” entries come from secondary coverage. Live Hub metadata is checked against each entry and any disagreement is flagged on the card.
